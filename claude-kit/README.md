# Набор для Claude Code: сайт калаев.рф

Набор правил и инструментов. С ним Claude Code в проекте сайта чинит найденные проблемы, пишет статьи по единому стандарту и проверяет себя перед выкладкой.

## Что внутри

| Файл | Что делает |
|---|---|
| `CLAUDE.md` | Главный документ. Claude читает его в начале каждой сессии: факты об авторе, запреты, стандарт статьи, разметка, бэклог исправлений |
| `.claude/skills/geo-audit/` | Навык «проверь сайт»: `audit.py` находит брак в сборке и не даёт выложить сайт с ошибками |
| `.claude/skills/geo-fix/` | Навык «исправь по стандарту»: пошаговая переделка статей и `sync_sitemap.py` для честных дат в sitemap |

## Как установить (5 минут)

1. Откройте папку проекта сайта, ту, где лежат `package.json` и `astro.config.*`.
2. Скопируйте туда:
   - `CLAUDE.md` в корень проекта. Если там уже есть свой CLAUDE.md, вставьте содержимое этого файла в конец своего;
   - папку `.claude/skills/` целиком, рядом с CLAUDE.md. Если папка `.claude` уже есть, просто добавьте в неё `skills/geo-audit` и `skills/geo-fix`.
3. Запустите Claude Code в этой папке и напишите:

   > Прочитай CLAUDE.md. Запусти geo-audit и покажи отчёт. Потом сделай технические пункты бэклога (раздел 9), снова запусти проверку и покажи, что изменилось. Не выкладывай без моего «да».

4. Дальше по пачкам:

   > Сделай geo-fix для следующих 10 статей по бэклогу.

## Что нужно для работы

- Python 3.8+ (обычно уже есть). Сторонние библиотеки не нужны.
- Сборка сайта командой `npm run build` в папку `dist/`. Если команда или папка другие, скажите об этом Claude, он поправит.

## Что эта система не делает

- Не публикует на Дзене, vc.ru, b17 и в соцсетях. Готовит только черновики в `drafts/`.
- Не выдумывает источники и факты о вас. Чего не знает, пометит `TODO` и спросит.
- Не выкладывает сайт сама. Выкладка только после вашего «да».

Основание для правил: исследование `REPORT.md` в этом репозитории.
