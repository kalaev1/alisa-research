# geo-fix

Работай по CLAUDE.md. Жёсткие правила раздела 3 важнее всего, что написано здесь.

## 0. Перед началом

1. `npm run build && python3 .claude/skills/geo-fix/sync_sitemap.py dist && python3 .claude/skills/geo-audit/audit.py dist > audit-before.md`
2. Выбери пачку: сначала все ERROR, потом 10 статей по порядку из CLAUDE.md, раздел 9.
3. Найди исходники страниц в `src/` (контент-коллекции, `.md` / `.mdx` / `.astro`). Правь исходник, а не `dist/`.

## 1. Технические правки (ERROR, один раз на весь сайт)

Делай их в общих местах (layout, компонент статьи, astro.config, public/), а не в каждой странице:
- Person с `@id` на /about/, author через `@id` в Article (CLAUDE.md, раздел 6).
- byline «Опубликовано · Обновлено · Автор» в layout статьи и пособия, данные из тех же полей, что `datePublished` и `dateModified`.
- og:type `article` и абсолютный og:image в layout статьи.
- Одно описание ProfessionalService.
- lastmod в sitemap: `serialize` в `@astrojs/sitemap` и `sync_sitemap.py`.
- robots.txt, llms.txt, страница /work/ (CLAUDE.md, разделы 2 и 7).

## 2. Одна статья: порядок правки

Для каждой статьи пачки:

1. **Прочитай статью целиком.** Пойми, на какой вопрос она отвечает. Сверь H1 и title с этим вопросом.
2. **answer-lead.** Напиши первым абзацем прямой ответ на вопрос из H1: 2-3 предложения, 40-70 слов, начинается с «Если коротко,». Главный вывод и, для тем о теле, «лечит … врач». Бывший первый абзац (сценку, эмпатию) перенеси вторым. Добавь абзацу `class="answer-lead"`.
3. **Подзаголовки-вопросы.** H2 переформулируй как вопросы, которые реально задают («Может ли … от нервов?», «Как отличить … ?», «Что делать, если … ?»). Первое предложение под каждым H2 отвечает на вопрос.
4. **Медицинский маршрут.** Для тем о теле, беременности, сне, сердце, давлении, ЖКТ раздел «Сначала исключите медицинские причины» обязателен: какие обследования и какой врач.
5. **Источники.** 2-5 пунктов по правилам CLAUDE.md, раздел 5. Каждый ты открыл и прочитал. Привяжи 1-2 факта в тексте к источнику («по обзору … 2021 года»). Если проверенного источника нет, перепиши утверждение осторожнее и запиши `TODO` в отчёт владельцу. **Выдумывать нельзя ни при каких условиях.**
6. **FAQ.** 4-6 разных по смыслу вопросов, ответ 2-4 предложения. Удали синонимичные повторы. Видимый текст и FAQPage совпадают.
7. **Ссылки.** «Читайте также»: хаб `/guides/…` своей темы и 2-3 соседние статьи. Проверь, что ссылки живые.
8. **Дата.** Если правка содержательная (пункты 2, 3, 5 или новые факты), обнови `dateModified` и строку «Обновлено» на сегодняшнюю дату. Если правил только разметку или опечатки, дату не трогай.
9. **Тон.** Голос автора не менять: «вы», тепло, просто, без канцелярита, без длинных тире.

## 3. После пачки

1. `npm run build && python3 .claude/skills/geo-fix/sync_sitemap.py dist && python3 .claude/skills/geo-audit/audit.py dist > audit-after.md`
2. Сравни с `audit-before.md`: ERROR должно стать 0, CONTENT по пачке тоже 0.
3. Отчёт владельцу:
   - список исправленных страниц;
   - TODO по источникам и фактам, которые ждут его решения;
   - что осталось по бэклогу;
   - напоминание, что выкладывать можно после его «да».
4. Коммит: `geo-fix: {тема пачки}, {N} статей (answer-lead, источники, FAQ)`.
5. Отметь сделанное в CLAUDE.md, раздел 9 (галочки).

## 4. Черновики для внешних площадок (по просьбе владельца)

Если владелец просит текст для Дзена, vc.ru или b17: сделай сжатую адаптацию статьи (не копию), 40-60% объёма, со своим answer-lead и ссылкой «Полная версия с источниками: https://калаев.рф/articles/{slug}/» и подписью «Алан Калаев, практический психолог». Сохрани в `drafts/{площадка}/{slug}.md`. Ничего не публикуй сам.
