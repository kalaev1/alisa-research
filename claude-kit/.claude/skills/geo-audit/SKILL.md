# geo-audit

## Когда запускать

- Перед любой выкладкой сайта. Без 0 ERROR выкладывать нельзя (CLAUDE.md, правило 3).
- Когда владелец просит проверить сайт или спрашивает, что исправить.
- После каждой пачки правок навыком `geo-fix`.

## Шаги

1. Собери сайт и выровняй даты в sitemap:
   ```bash
   npm run build
   python3 .claude/skills/geo-fix/sync_sitemap.py dist
   ```
2. Запусти проверку:
   ```bash
   python3 .claude/skills/geo-audit/audit.py dist                          # весь сайт
   python3 .claude/skills/geo-audit/audit.py dist --only /articles/psihosomatika-   # часть сайта
   python3 .claude/skills/geo-audit/audit.py dist --live                   # плюс живой сайт: www, index.html, charset
   ```
   Код выхода 1 означает, что есть ERROR.
3. Отчитайся владельцу коротко, по-русски, без длинных тире:
   - сколько ERROR, CONTENT, WARN;
   - что из ERROR чинишь сейчас;
   - сколько статей ещё не доведены до стандарта (CONTENT) и какая пачка следующая по бэклогу из CLAUDE.md, раздел 9.

## Как читать результат

| Сообщение | Что значит | Что делать |
|---|---|---|
| lastmod в sitemap не равен dateModified | sitemap не синхронизирован | запусти `sync_sitemap.py`; если повторяется, поправь `serialize` в `@astrojs/sitemap` |
| в sitemap нет lastmod | у страницы нет дат в разметке | добавь datePublished и dateModified в Article (реальные даты, не сегодняшнюю) |
| страница не попала в sitemap / в sitemap есть адрес, которого нет в сборке | sitemap рассинхронизирован со сборкой | проверь фильтры `@astrojs/sitemap`, удалённые и переименованные страницы (для переименованных нужен 301) |
| запрещённая формулировка квалификации | где-то написано «клинический психолог» | приведи к CLAUDE.md, раздел 2 |
| вопрос из FAQPage не виден на странице | разметка расходится с текстом | разметка строится из тех же данных, что и видимый FAQ |
| нет видимой строки «Опубликовано/Обновлено» | дата только в коде | добавь byline в layout статьи |
| первый абзац не оформлен как ответ / похоже на сценку | ответа в начале нет | навык `geo-fix`, шаг «answer-lead» |
| нет блока «Источники» | нет ни одного источника | навык `geo-fix`, шаг «источники» (только проверенные!) |
| у раздела нет своей страницы | на хостинге будет 403 | сделай страницу-список или 301 |

Эвристики CONTENT не идеальны. Если считаешь, что сообщение ложное, проверь страницу глазами и напиши владельцу, почему оставляешь как есть. Никогда не «обманывай» проверку (например, не ставь `class="answer-lead"` на абзац, который не является ответом).
